## About me

I am a Full Stack Developer and Computer Engineer focused on building complete digital products, not just isolated screens or endpoints.

My work covers the full software lifecycle: product discovery, architecture, database modeling, frontend and backend development, integrations, deployment and production support.

I currently work mainly with **Java, TypeScript, JavaScript and C#**, developing SaaS platforms, management systems, mobile applications and business integrations.

- Strong experience with **React, React Native, Angular, Node.js, NestJS, Java and Spring Boot**
- Product development from scratch, including architecture and technical decisions
- REST APIs, authentication, multi-tenant systems and third-party integrations
- Docker-based infrastructure, CI/CD and production deployments
- Practical experience translating business requirements into maintainable software
