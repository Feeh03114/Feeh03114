## Como eu trabalho

Começo pela regra de negócio. Depois defino os dados e o fluxo da solução, implemento o que precisa ser feito e acompanho a entrada em produção.

Gosto de decisões simples, código que outra pessoa consiga manter e arquitetura compatível com o tamanho real do projeto. Nem todo sistema precisa nascer como se fosse atender um bilhão de usuários na terça-feira.
